# ADR 0004 — PaperLab gets its own identity

Status: accepted · 2026-10-15

## Context
Owner chose "its own playful identity" over the hub's editorial system.

## Decision
- Dark lab canvas by default (light theme supported), with a spectrum: each lab owns one hue, running warm → cool up the ladder, so the ladder itself reads as a gradient.
- Type: a rounded grotesk for display and UI (OFL, self-hosted; candidate: Bricolage Grotesque), JetBrains Mono for every number and formula.
- Motion is part of the identity: things ease, settle and glow; nothing snaps. Reduced motion collapses to end states.
- A mark: ten dots on a rising line.
- The hub's tokens are not imported; PaperLab's `tokens.css` is its own.

## Consequences
The hub's case page and OG image for PaperLab are refreshed after launch to match.
