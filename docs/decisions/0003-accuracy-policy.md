# ADR 0003 — Accuracy policy: exact kernels, real weights, labelled toys

Status: accepted · 2026-10-15

## Decision
- Labs 1, 2, 3, 6, 7, 8: maths in TypeScript, pure, deterministic (seeded), with Vitest tests against hand-computed or NumPy-generated reference values checked into `tests/fixtures/`.
- Labs 4, 5, 9: real pretrained weights (small public embedding set; a tiny CNN we train and export to ONNX; a tiny diffusion model or a precomputed trace). The source, training script and licence live in `models/<lab>/README.md`.
- Lab 10: a real open-weight model (ADR 0005) instrumented so that attention is read from the model, not recomputed; a validator asserts instrumented logits equal the original.
- Any synthetic weights show a persistent in-scene badge "toy weights" with a one-line reason.
- Captions never state a number the scene is not computing.

## Consequences
CI runs every lab's tests; a lab without tests does not ship. Reference fixtures are regenerated by a documented script, never edited by hand.
