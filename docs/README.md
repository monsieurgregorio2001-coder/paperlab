# Docs

| Where | What |
| --- | --- |
| `VISION.md` | The product in one page: the ladder, the principles. |
| `plan/` | Dated implementation plans. A plan is a contract: scope, phases, acceptance checks. |
| `decisions/` | ADRs, numbered, dated, never edited after acceptance (superseded ones point forward). |
| `audits/` | Dated reviews with measurements and ranked recommendations. |
| `TRACKER.md` | Live status of every planned item, updated in the commit that moves it. |
| `CHANGELOG.md` | User-visible changes, newest first. |

Conventions: ISO dates, Asia/Manila. Every number in the app or the docs traces to a test, a config line or a measurement, recorded beside it.
