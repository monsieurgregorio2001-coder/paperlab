# PaperLab — conventions

A playground where you can see models think. Read `docs/VISION.md` first, then `docs/TRACKER.md` for what is in flight. Stack: React 18 + TypeScript + Vite + Three.js (direct, no r3f). Deployed to GitHub Pages at `/paperlab/`.

## Structure
- `src/labs/<slug>/` — one folder per lab: `math.ts` (pure, tested), `scene.ts` (Three.js), `Lab.tsx` (controls + captions), `tour.ts`, `index.ts` (registry entry).
- `src/engine/` — `useScene`, renderer setup, frame probe, shared materials.
- `src/ui/` — chrome, tour runner, maths drawer, badges.
- `models/<lab>/` — training/export/instrumentation scripts and a README with source, licence and accuracy. Weights are fetched at runtime, never committed.
- `tests/fixtures/` — reference values generated by `scripts/fixtures.py`; never hand-edited.

## Rules
- Maths is pure TypeScript with Vitest tests against fixtures (ADR 0003). A lab without tests does not ship.
- Captions read values from the same state the scene renders; never hard-code a number in copy.
- Synthetic weights show the in-scene "toy weights" badge.
- Every scene: WebGPU → WebGL fallback → no-WebGL static state; reduced motion → end states; DPR ≤ 2 (1.5 on phones); loop paused when hidden or off screen; frame probe ≤ 8 ms on M1 Air.
- Colours and type come from `src/tokens.css` (ADR 0004); no hex in components.
- Voice: short, plain, first person for the author's notes. Numbers in JetBrains Mono.
- Borrowed code keeps its licence header (ADR 0007).

## Process
- One phase per branch (`phase-N/name`), PR into `main`, `main` always deployable.
- Every PR updates `docs/TRACKER.md` and `docs/CHANGELOG.md`; structural choices get an ADR.
- Before pushing: `npm test`, `npm run build`, `npm run check` (Playwright smoke + axe + frame probe + bundle budget).
