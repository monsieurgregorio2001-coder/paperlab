# PaperLab: Attention

Type a sentence. See what each word reads. Then break the math.

This is one attention layer at toy size. The four heads use hand-set weights on the same tested softmax(QK^T / sqrt(d_k)) V kernel that the receipt on the page counts. Switch off Position, Scaling, or the Causal mask and the threads show what breaks.
